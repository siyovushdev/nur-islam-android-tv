# Телефонный Debug APK

Тестовая сборка интерфейса для Android 8.0 / API 26 и новее. Kotlin + Jetpack Compose, без WebView. Основана на реализации PR #13; его merge для сборки не нужен.

## Скачать и установить без ADB

1. В GitHub Actions откройте успешный запуск Android для ветки `codex/phone-debug-preview`, скачайте artifact **nur-islam-phone-debug**. Для скачивания Actions artifacts нужна авторизация в GitHub.
2. Распакуйте ZIP и откройте **Nur-Islam-Phone-Debug.apk** в файловом менеджере телефона.
3. Если Android попросит, разрешите «Установку неизвестных приложений» только этому файловому менеджеру/браузеру, установите APK, затем отзовите это разрешение.
4. В списке приложений появится **«Нур Ислам · Телефон (тест)»**. Root, ADB и назначение HOME не требуются.

`applicationId = dev.nurislam.tv.phone.debug`: эта сборка не обновляет и не читает данные TV-пакетов `dev.nurislam.tv` / `dev.nurislam.tv.debug`. В телефоном APK отсутствуют HOME intent-filter, Device Admin receiver и provisioning Activity. TV-контроллер настройки не создаётся.

## Проверка интерфейса

- Кнопка **Настройки** сверху открывает меню сразу. Тема Elegant / Classic и масштаб 85 / 100 / 115% меняются нажатием; список прокручивается пальцем.
- Ориентация — режим отрисовки табло. AUTO следует форме окна; можно физически повернуть телефон. Программные CW/CCW поворачивают само табло; настройки и подтверждение остаются прямо. Полное табло вписывается с полями, поэтому поворот не обрезает строки. Подтвердите изменение за 15 секунд либо дождитесь отмены.
- Название/местоположение редактируются обычной клавиатурой телефона. Системная кнопка «Назад» закрывает настройки, а с табло выходит из приложения.
- **Расписание → Импорт JSON — выбрать файл** открывает системный picker. Перед применением доступны проверка/предпросмотр, затем подтверждение источника. Формат — [SCHEDULE_FORMAT.md](SCHEDULE_FORMAT.md). Импорт, смена и откат используют тот же репозиторий, что и TV.
- **Официальный календарь в APK не вложен.** При первом запуске строки показывают «—», пока не импортирован подходящий утверждённый год. Синтетические значения на тестовых скриншотах не являются расписанием мечети и не включены в установленный APK.
- Пакет не запрашивает интернет и не предлагает HOME, Device Owner или kiosk. Проверка на телефоне не заменяет аппаратную приёмку ТВ.

## Сборка и подпись

```
./gradlew :app:assemblePhoneDebug :app:testPhoneDebugUnitTest :app:lintPhoneDebug
```

Исходный APK: `app/build/outputs/apk/phoneDebug/app-phoneDebug.apk`. В artifact он переименован в `Nur-Islam-Phone-Debug.apk`; рядом лежат SHA-256 файла и вывод `apksigner verify --verbose --print-certs`. Это подписанный Debug, не production Release. Ключ Debug локальной машины и нового CI-run может различаться: для обновления уже установленной тестовой копии нужен тот же ключ. Не удаляйте приложение ради обновления без сохранения нужного JSON — удаление стирает только его собственные настройки и импорт.

TV-задачи `assembleDebug` и `assembleRelease` сохраняют прежние пакеты/манифесты. Телефонный `phoneDebug` не меняет настройку TV. Никаких установок/команд на H728 для этой работы не требуется.
