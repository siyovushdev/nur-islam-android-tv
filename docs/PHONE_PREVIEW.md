# Телефонный Debug APK

Тестовая сборка интерфейса для Android 8.0 / API 26 и новее. Kotlin + Jetpack Compose, без WebView. Включает принятые исправления PR #13/#14 и отдельную настройку икамата; см. [инструкцию](IQAMAH.md).

## Скачать и установить без ADB

1. В GitHub Actions откройте успешный запуск Android для нужного PR/ветки (для Issue #18 — итоговый stack `codex/product-readiness`), скачайте artifact **nur-islam-phone-debug**. Для скачивания Actions artifacts нужна авторизация в GitHub.
2. Распакуйте ZIP и откройте **Nur-Islam-Phone-Debug.apk** в файловом менеджере телефона.
3. Если Android попросит, разрешите «Установку неизвестных приложений» только этому файловому менеджеру/браузеру, установите APK, затем отзовите это разрешение.
4. В списке приложений появится **«Нур Ислам · Телефон (тест)»**. Root, ADB и назначение HOME не требуются.

`applicationId = dev.nurislam.tv.phone.debug`: эта сборка не обновляет и не читает данные TV-пакетов `dev.nurislam.tv` / `dev.nurislam.tv.debug`. В телефоном APK отсутствуют HOME intent-filter, Device Admin receiver и provisioning Activity. TV-контроллер настройки не создаётся.

## Проверка интерфейса

- Кнопка **Настройки** сверху открывает меню сразу. Тема Elegant / Classic и масштаб 85 / 100 / 115% меняются нажатием; список прокручивается пальцем.
- Ориентация — режим отрисовки табло. AUTO следует форме окна; можно физически повернуть телефон. Программные CW/CCW поворачивают само табло; настройки и подтверждение остаются прямо. Полное табло вписывается с полями, поэтому поворот не обрезает строки. Подтвердите изменение за 15 секунд либо дождитесь отмены.
- Название/местоположение редактируются обычной клавиатурой телефона. Системная кнопка «Назад» закрывает настройки, а с табло выходит из приложения.
- **Расписание → Импорт JSON / XLSX — выбрать файл** открывает системный picker. Перед применением доступны проверка/предпросмотр, затем подтверждение источника. Формат — [SCHEDULE_FORMAT.md](SCHEDULE_FORMAT.md). Импорт, смена и откат используют тот же репозиторий, что и TV.
- Для личной демонстрации **только PhoneDebug** разрешает полностью валидный тестовый JSON с `approved=true`: отметьте «Понимаю: тестовое расписание не утверждено мечетью», затем примените. Постоянный контрастный баннер «ТЕСТОВОЕ РАСПИСАНИЕ» отличает такое табло от рабочего. `approved=false` не применяется; в TV Release тестовые источники остаются заблокированы.
- **Официальный календарь в APK не вложен.** При первом запуске строки показывают «—», пока не импортирован подходящий утверждённый год. Синтетические значения на тестовых скриншотах не являются расписанием мечети и не включены в установленный APK.
- Пакет не запрашивает интернет и не предлагает HOME, Device Owner или kiosk. Проверка на телефоне не заменяет аппаратную приёмку ТВ.

## Сборка и подпись

```
./gradlew :app:assemblePhoneDebug :app:testPhoneDebugUnitTest :app:lintPhoneDebug
```

Исходный APK: `app/build/outputs/apk/phoneDebug/app-phoneDebug.apk`. В artifact он переименован в `Nur-Islam-Phone-Debug.apk`; рядом лежат SHA-256 файла и вывод `apksigner verify --verbose --print-certs`. Это подписанный Debug, не production Release. Начиная с поставки Issue #18 подписывается постоянным тестовым ключом; сертификат закреплён в репозитории, каждое следующее обновление проверяется с сохранением данных. **Первая миграция со старой CI-подписи несовместима поверх**: сначала сохраните исходники и параметры, затем один раз переустановите тестовую копию. [Подробности и публичный сертификат](SIGNING_AND_UPDATES.md).

В artifact включён **TEST-Kazan-2026.xlsx** для личной проверки: это исходные значения без корректировки, не утверждённый календарь мечети. Импортируйте его через системный выбор файла/папки, отметьте понимание тестового статуса и примените. Табло постоянно показывает «ТЕСТОВОЕ РАСПИСАНИЕ». Правила икамата и даты Рамадана по умолчанию отсутствуют; настройте их отдельно. [XLSX](XLSX_IMPORT.md), [Рамадан](RAMADAN.md).

TV-задачи `assembleDebug` и `assembleRelease` сохраняют прежние пакеты/манифесты. Телефонный `phoneDebug` не меняет настройку TV. Никаких установок/команд на H728 для этой работы не требуется.
