# Установка и загрузка данных

1. Скачайте **TV Release** для телевизора или **Phone Release** для телефона.
2. Откройте APK и разрешите установку из выбранного приложения, если Android попросит.
   При обновлении нажмите «Обновить». Удалять предыдущую Release-версию не нужно.
3. Запустите «Нур Ислам». На телевизоре нажмите OK один раз; на телефоне нажмите
   видимую кнопку **Настройки**.
4. Нажмите **Загрузить расписание**, выберите готовый JSON или поддерживаемый XLSX,
   проверьте место и год, нажмите **Применить**, затем **Вернуться к табло**.
5. Если у мечети есть готовый календарь икамата, Рамадана и событий, нажмите
   **Загрузить календарь мечети**, выберите его JSON и нажмите **Применить**.
6. Тема, язык, размер текста и поворот находятся в **Внешний вид**. Изменённый поворот
   нужно подтвердить за 15 секунд; без подтверждения вернётся прежний.

Галочек утверждения источника нет. Правильные религиозные даты и времена готовит
мечеть в исходном файле; приложение проверяет формат и согласованность данных.
Тестовые примеры заметно помечаются на табло и одинаково работают на TV и телефоне.

Файлы можно заранее скачать на телефон или перенести на USB телевизора.
Если системный выбор неудобен, откройте **Загруженные данные → Выбрать папку с файлами**.
Один раз разрешите доступ к папке; затем выбирайте файл пультом в списке приложения.
Наличие системного выбора USB/папок зависит от прошивки. Резервный способ с ADB
описан для специалиста; он не нужен на устройствах с работающим файловым диалогом.

Неверный файл не заменяет текущие данные. Предыдущие версии можно вернуть из
**Загруженные данные** отдельно для расписания и для календаря мечети.
Без расписания нужного года приложение показывает часы и просьбу загрузить данные.
Чужой год и времена из другого региона не подставляются.

**Запуск при включении телевизора** — отдельная необязательная настройка.
Она не нужна для обычного использования. На телефоне такого пункта нет.
Перед изменением основного экрана на рабочем ТВ нужен согласованный план возврата.

Для демонстрации используйте оба файла из `data/examples/`. Они содержат вымышленные
времена и даты на 2026 год. Для проверки в другом году нужны подготовленные файлы этого
года, а не изменение системных часов рабочего устройства. Формат: `MOSQUE_CALENDAR_FORMAT.md`.

Release `dev.nurislam.tv` / `dev.nurislam.tv.phone` обновляется существующим постоянным
Release-ключом. Debug — отдельные пакеты; их данные автоматически в Release не переносятся.
До аппаратной приёмки выпуск обозначается RC/pre-release, хотя сами APK — Release без отладки.
