## Порядок работы с Codex

1. Codex самостоятельно разбивает общую цель на удобные технические подшаги и продолжает до выполнения ПО-критериев.
2. Код — в feature-ветке, отчёт, тесты, Compose-скриншоты и один Draft PR (если объём разумен).
3. Нет автоматического merge без решения владельца.
4. Неизвестное железо/официальное расписание — отдельные реальные блокеры полевого релиза, а не повод остановить доступную работу.

## Не делать в первой итерации

- Встраивать HTML/WebView или переносить JS из референса.
- Делать сервер, облачный кабинет, рекламу, мультимедиа или телеметрию без требования.
- Автоматически выводить «официальные» времена из непроверенного астрономического калькулятора.
- Добавлять фоновые службы только ради удержания экрана, не проверив штатные механизмы Android TV.
