# Импорт Excel и файлов с пульта

В настройках → «Расписание» доступны JSON и XLSX. Интернет не нужен.

## Обычная установка, без ADB

1. Скопируйте файл на USB или в локальную папку устройства.
2. Выберите «Импорт JSON / XLSX — выбрать файл». Системный диалог должен поддерживать пульт.
3. Если «Недавние» неудобны, выберите «Выбрать папку с JSON / XLSX». Один раз укажите папку USB/локального хранилища и разрешите чтение. Затем список папок и файлов открывается внутри Nur Islam: ↑↓/OK/BACK или касание.
4. На Android 11+ системный диалог может запрещать корень накопителя, Downloads и Android/data. Создайте отдельную папку `NurIslam` и выберите её. Приложение не запрашивает полный доступ к накопителю.
5. Проверьте год, источник, все показанные времена и предупреждения. Подтвердите источник и нажмите «Применить расписание». Предыдущая версия остаётся для отката.

Доступ к выбранной папке сохраняется. При извлечении USB, отзыве разрешения или сбое провайдера выберите папку заново. Если прошивка не предоставляет работающий SAF, универсального способа через пульт приложение гарантировать не может: требуется аппаратная проверка либо резервный импорт из [TV_OPERATIONS.md](TV_OPERATIONS.md).

## Поддерживаемый XLSX

Формат Казань: один лист с годом 2000–2200, заголовки в строках 1/2,
A — Казань, B — дата, C–J — сухур, «Совершается в мечети», восход, зенит,
Зухр, Аср, Магриб, Иша. Полный год, без дубликатов и пропусков.
Текстовые даты YYYY-MM-DD / DD.MM.YYYY, числовые даты Excel 1900/1904,
времена HH:mm или числовые доли суток. Секунды не округляются до минут;
допускается только машинная погрешность двоичного представления точной минуты.
Пустые форматированные строки исходного файла игнорируются.

Формулы **не исполняются**. Читаются только сохранённые результаты, если они есть
и имеют допустимый тип/значение. Предпросмотр предупреждает о числе формул и возможной
давности их результатов. Формулы без результата и ошибки Excel отклоняются.
Макросы, внешние ссылки, старый XLS, DTD/XML-сущности, небезопасные ZIP и слишком
большие файлы не поддерживаются. Пределы: 8 МиБ вход, 24 МиБ распаковка,
12 МиБ на часть, 200 частей, 200000 ячеек, 20000 строк, 32 уровня XML.

Конвертер сохраняет **те же минуты**, включая Иша 18:50. Он не утверждает источник,
не задаёт икамат и всегда оставляет `fajrMeaning=UNCONFIRMED`.
В TV требуется явное подтверждение администратором утверждения источника мечетью.
В PhoneDebug Excel получает постоянную маркировку тестового источника и отдельное
согласие на демонстрацию. Правила JSON `approved=false` не изменены: такой JSON применить нельзя.
Внутреннее хранение и откат используют прежний JSON-контракт и AtomicFile.
SHA-256 Excel записывается в ревизию для сопоставления исходного файла.

## Независимая сверка исходника

`app/src/test/resources/xlsx` содержит копию предоставленного исходного файла,
из которой удалены приватные метаданные, и независимый TSV-эталон. Все значения
и кэш формул сохранены. `ScheduleXlsxTest` сравнивает 365×8 времён с TSV.
Для повторения независимого извлечения используйте `scripts/audit-source-xlsx.py`
с read-only openpyxl 3.1.5 в отдельном Python-окружении и локальным оригиналом.
Это проверка точности конвертации, а не религиозное утверждение расписания.

Ограничения выбора папки соответствуют [Android Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files).
Различие формулы и сохранённого результата описано в [Microsoft Open XML](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-formulas).
