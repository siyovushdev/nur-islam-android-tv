# Необязательный блок Рамадана

Настройки → «Рамадан». По умолчанию блок выключен, дат нет.
Это отдельные параметры; импорт/откат JSON или XLSX не меняет их и не задаёт даты праздников.

1. Добавьте период. Введите григорианский **первый день поста**, не вечер начала религиозного месяца.
2. При наличии подтверждённой даты введите Ураза-байрам. Между датами должно быть 29 или 30 дней поста. Дата праздника не является днём поста.
3. Укажите источник/документ. Отметьте «Даты утверждены мечетью» только после согласования введённых дат. Изменение даты или источника снимает подтверждение. Тестовый источник нельзя отметить утверждённым.
4. Добавьте запись в черновик. Включите блок, проверьте предпросмотр на дату устройства и сохраните с отдельным подтверждением. Назад позволяет отменить несохранённый черновик.
5. Результат сохраняется локально. Предыдущая версия доступна для подтверждаемого отката. После ошибки записи черновик остаётся для исправления/повторения.

Дата вводится с экранной цифровой клавиатуры ГГГГММДД (например, восемь цифр из вашего документа), пультом или клавиатурой телефона. Год берётся из введённой даты; нет автоматически подставленных дат. Можно заранее добавить следующий год. Записи различаются первым днём поста: допускаются два непересекающихся периода в одном григорианском году. Дубли и пересечения запрещены.

## Что показывает табло

- До первого дня поста: целое число календарных дней по Europe/Moscow.
- Во время: номер дня поста. При заданной дате праздника — дни до Ураза-байрама.
- На утверждённую дату праздника: поздравление ровно один календарный день.
- Затем блок скрывается, либо показывает ближайший настроенный будущий период этого/следующего года. Даты не переносятся на следующий год автоматически.
- Без Ураза-байрама известны первые 29 дней. Возможный 30-й день **не объявляется днём поста**: блок скрывается с диагностикой в настройках до уточнения окончания.
- Неуказанные/неподтверждённые/просроченные даты не дают ложного отсчёта. Неподдерживаемый год часов или обнаруженный скачок часов приостанавливает блок. Сначала сверьте Android-время, затем подтвердите часы в настройках. Приложение не может определить правдивость внешне правдоподобных неверных часов без источника времени.

Язык следует общей настройке: русский, татарский или оба. Блок занимает существующий Footer вместо орнамента: времена молитв, часы, икамат и геометрия таблицы не уменьшаются и не сдвигаются. Он не объявляет начало религиозных суток в полночь.

## Проверка

Для личной проверки в тестовой сборке используйте самостоятельно выбранные демонстрационные даты и оставьте подтверждение выключенным: они не должны попасть на табло. Сценарии отображения с подтверждёнными тестовыми данными проверяются автоматическими UI-тестами; их значения не вложены в APK как официальные.

Unit: границы 29/30 дней, московская полночь, смена года/межгодовой период,
отсутствующее окончание, неверные даты/источник, повтор/пересечения, обе локализации,
ошибки до и после commit, повреждение/резерв/откат.
Robolectric API 26/29/30/31/34/35: AtomicFile + восстановление независимо от календаря намазов.
Compose: ввод D-pad и касанием, ошибки/отмена/подтверждение/сохранение; обе темы,
portrait/landscape/CW/CCW, три масштаба и языка; сравнение координат строк до/после включения.
Это программные проверки; они не подтверждают даты мечети и работу панели 72 часа.
