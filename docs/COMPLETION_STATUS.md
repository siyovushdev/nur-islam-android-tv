## Внешняя приёмка

Мечеть подтверждает авторитетность Excel, значение «Мәчеттә укыла», спорные значения Иша,
правила икамата/Джума и даты Рамадана. Программа не определяет их самостоятельно.
Владельцу предстоят согласованные проверки реальных HOME/перезагрузки/питания/CEC/SAF,
пульта и фактический 72-часовой прогон на H728 и конкретной модели Xiaomi.
Ни один из этих аппаратных сценариев в этой работе пока не выполнен.

## Интеграционный stack

[#20 — Рамадан](https://github.com/siyovushdev/nur-islam-android-tv/pull/20), HEAD `532c168`: [CI PASS](https://github.com/siyovushdev/nur-islam-android-tv/actions/runs/40186538461), включая повтор phone job после внешнего ANR Pixel Launcher.
Текущая ветка `codex/product-readiness` содержит оба PR и добавляет постоянную подпись,
проверку APK-обновления, нативные эмуляторные сценарии и дополнительные исправления аудита.
[Матрица проверок](QA_MATRIX.md) отделяет уже полученный PASS от ещё не выполненного native CI.
Новые исправления: безопасная обработка испорченной ссылки/ошибки выбора папки,
OPENABLE и старт SAF вне «Недавних», предупреждение вытеснения текущего календаря,
кооперативная отмена распаковки/XML с сохранением CancellationException.

Первый новый native CI `a19fa2c`: build и постоянная подпись PASS, emulator jobs FAIL.
Phone: один BACK в SAF поднялся из Downloads к корню, а не закрыл диалог — скрипт
исправлен на ограниченный выход по наблюдаемому экрану DocumentsUI. TV: назначение HOME
не подтверждено; штатный resolver восстановлен. Проверки HOME теперь используют явного
текущего Android-пользователя и сохраняют stdout/фактический resolver, а core instrumentation
запускается до HOME. До успешной повторной проверки native пункты не объявляются PASS.
Дополнительно усилен TV write-boundary запрет тестовых источников, включая явно тестовое
имя XLSX; JSON-валидатор и времена не менялись.

Native TV API 34 на `0ed2f90`: три настоящих instrumentation-теста baseline PASS
(53,9 с): XLSX 2920 значений/откат, D-pad/темы/повороты/масштабы/recreate,
Рамадан/сохранение. HOME: Android принял роль, но resolver остался штатным;
это не успешное назначение. Повторная проверка фиксирует также реальный HOME launch,
возврат resolver + role и выделяет ограничение TV-прошивки отдельно от core suite.
Положительный HOME-control проверяется на стандартном API 35 emulator с тем же TV APK.
Добавлена защита восстановления pending SAF результата после пересоздания Activity/процесса:
выбранный файл открывает предпросмотр заново, применение остаётся заблокированным без checkbox.
Robolectric API 26/35 regression этого сценария PASS; native process death ещё проверяется.
