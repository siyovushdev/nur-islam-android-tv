# Исходные материалы и спорные данные

**Источник референса:** предоставленные владельцем два HTML («Нур Ислам v22 чистый.html» и «Нур Ислам.html», версия v36) и таблица «vremena_namazov_RT_2026_0.xlsx». Это **примеры для анализа**, не встроенный UI Android-приложения.

## Что обнаружено

- В HTML год не записан в ключах таблицы: только день и месяц. На 2027 год эти данные переносить нельзя; 29 февраля следующего високосного года в примере отсутствует.
- В Excel есть «Сәхәр тәмам», «Мәчеттә укыла», восход, зенит, Зухр, Аср, Магриб, Иша. «Мәчеттә укыла» в исходном файле переведено как «Совершается в мечети»: не переименовывать без согласования в «азан» или «начало Фаджра».
- В HTML версии v22 и v36 совпадают 365 дневных записей, но **142 дня отличаются от Excel только по Иша**: HTML 18:45, Excel 18:50. Периоды: 01.01–24.02 и 06.10–31.12. Это требует решения мечети, не самовольного исправления.
- В обоих HTML есть приблизительные/ручные даты Рамадана, в том числе будущие. Нельзя считать их утверждёнными.
- Интервалы до икамата в HTML: Фаджр +10, Зухр +15, Аср +10, Магриб +5, Иша +15 минут. Их происхождение не подтверждено Excel и должно быть согласовано.
- В версии v36 экран «Икамат» предусмотрен, но в коде не активируется; правила показа реализовать заново и проверить.
- Необычные значения при переходах сезонных расчётов в мае/августе Татарстана **не нормализовать** без официального пояснения; см. ДУМ РТ.

## Правила для новой реализации

1. Считать официальным только набор данных, утверждённый для конкретной мечети, года и населённого пункта.
2. Хранить локально годовой датасет с явным годом/датой и атрибутами source, revision, approved_at (если есть подтверждение).
3. Отдельно хранить локальное расписание икамата. Никогда не подставлять значения +5/+10/+15 из HTML по умолчанию.
4. Запретить незаметное использование данных вне диапазона дат.
5. Тесты сравнения делать по согласованному эталону, не по случайному ответу внешнего API.

Источник для проверки: https://dumrt.ru/ru/help-info/prayertime/

**Состояние:** необходим ответ мечети по Иша 18:45/18:50 и по «Мәчеттә укыла». Пока заблокирована релизная приемка времён.
