# Темы и настройки — согласованное требование (2026-10-23)

**Решение владельца:** Stitch не нужен. Приложение — **только Kotlin + Jetpack Compose**, без WebView и HTML-интерфейсов. Тема — нативное оформление одних и тех же данных, **не другой источник расписания**.

## Тема 1 — ELEGANT (по умолчанию)

Использовать уже реализованное в PR #8 оформление:
- исходная художественная картинка: [reference_original.png](reference_original.png);
- цветовая палитра и композиция: [DESIGN_SPEC.md](DESIGN_SPEC.md);
- рендеры Compose: [screenshots/portrait-1080.png](screenshots/portrait-1080.png), [screenshots/landscape-1080.png](screenshots/landscape-1080.png).

Тёмно-зелёный фон, спокойное матовое золото, изящная арка, геометрические мотивы, декоративные элементы и крупные часы. Все ключевые тексты — нативные Compose-компоненты; не превращать экран в один PNG.

## Тема 2 — CLASSIC (простая версия из HTML)

Визуальный первоисточник — **«Нур Ислам v22 чистый.html»**, предоставленный владельцем в переписке. HTML — **только пример внешнего вида**, не код приложения. Наш схематичный открываемый референс: [CLASSIC_REFERENCE.svg](CLASSIC_REFERENCE.svg).

Сохранить характерные признаки v22:
- ровный изумрудно-зелёный фон **#084F26** с очень мягким градиентом; **без** богатой архитектуры, фотографий, множества орнаментов и сильного свечения;
- яркие белые часы и татарская/русская дата, простая sans-serif типографика (визуально близкая Arial);
- основной акцент **#FFD76A**; выделение активного/следующего намаза золотистым фоном с тёмно-зелёным текстом;
- простая шапка «Нур Ислам», «Казан · Казань» и небольшой полумесяц;
- компактная таблица из тех же восьми времен: 5 обязательных намазов подчеркнуты, сухур/восход/зенит слегка приглушены, но обязательно читаемы;
- понятный блок следующего намаза: **название + точное время + отдельный отсчёт**. Не переносить ошибку оригинального CSS, где название и точное время скрыты;
- никаких мерцающих/мигающих эффектов. «Рамадан»/хиджру отображать только при подтверждённых данных, а не вычислять/угадывать из старого HTML.

Не копировать жёстко CSS-вёрстку v22 с `rotate(90deg)`. Поворот — существующий штатный нативный `RotatedBoard`.

## Общие принципы

- В обеих темах одинаковые 8 строк, одинаковые правила следующего намаза, одинаковая дата/время, подтверждение расписания, ошибки и настройки.
- Переключение темы **в реальном времени**, без перезапуска или потери расписания; сохранять тему между перезагрузками и процессными пересозданиями.
- Не допускать, чтобы будущие темы дублировали бизнес-логику. Предусмотреть расширяемые `BoardThemeId` + палитра/типографика/настройки декора; избегать переусложнения с динамическими плагинами и отдельными APK.
- Всегда проверять читаемость с 3–8 м; в вертикальном 1080×1920, горизонтальном 1920×1080, логическом повороте CW/CCW, 720p, 4K и fontScale 1.3.
- Макет образца содержит **фиктивные часы/времена**: их никогда не показывать как настоящие в Release.

## Настройки, доступные в РЕЛИЗНОМ APK

Путь в меню должен работать на простом Android TV пульте **без тачскрина, мыши, MENU и клавиатуры**. Например, долгим нажатием OK 3 секунды открывать админ-экран; выбрать и проверить реальный работающий вариант клавиш. Защиту от случайного открытия/изменений обеспечить явным входом и подтверждением критичных действий (опциональный PIN можно добавить без жёстко зашитого пароля). Всегда должна быть безопасная возможность выйти обратно к табло.

**Основной набор:**
1. **Тема:** Elegant / Classic; предпросмотр и моментальное применение; сохранение.
2. **Экран:** AUTO (по логическому окну), PORTRAIT_NATIVE, PORTRAIT_ROTATE_CW, PORTRAIT_ROTATE_CCW, LANDSCAPE. Для физически повёрнутого 1920×1080 ТВ выбирать ±90° явно: AUTO *не угадывает* положение корпуса.
3. **Безопасное переключение режима:** предварительный показ + подтверждение в течение короткого интервала. Если пульт/ориентация стали неудобны или нет подтверждения — возврат к прежнему режиму. Настройку сохранить только после подтверждения.
4. **Шрифт/масштаб:** небольшой диапазон масштабирования полезного текста без обрезки строк и кнопок; для обеих тем.
5. **Отображение:** татарский + русский (по умолчанию), а при необходимости показывать один из этих языков (опция, если не требует большого рефакторинга); не ломать локализацию даты.
6. **Название и местоположение мечети:** редактируемые подписи, только отображение. **Не менять часовой пояс/календарь** от одной замены подписи! Пока регион Казань, `Europe/Moscow` и локальный календарь привязаны к метаданным расписания.
7. **Расписание:** текущий год, источник, версия/ревизия и статус утверждения, команда импорта JSON (SAF с проверкой поддержки конкретного ТВ), предварительный просмотр, подтверждение, безопасный откат к предыдущей версии.
8. **Диагностика:** версия APK, системное время и временная зона, режим экрана, активная тема, актуальный год расписания, источник/ревизия, статус импорта; явная возможность сообщить об ошибке времени/данных. Не выводить чувствительные данные.

**Икамат:** предусмотреть отдельный раздел как следующую функциональную часть. Не показывать неподтверждённые интервалы и не переносить `+10/+15` из HTML автоматически. Возможность настраивать подтверждённый икамат для каждой молитвы согласовать до включения в релизный алгоритм.

**Эксплуатация:** на следующем этапе использовать штатные механизмы Android TV для HOME/autostart с безопасным возвратом к обычному лаунчеру; не маскировать аппаратные ограничения. Не включать принудительный kiosk по умолчанию без проверки.

## Критерии приёмки

- [ ] Обе темы действительно нарисованы Compose и сменяются из Release-настроек.
- [ ] Любые настройки экрана работают с пульта без MENU/клавиатуры/тачскрина и сохраняются после закрытия и повторного запуска.
- [ ] Для `PORTRAIT_ROTATE_CW/CCW` правильно отображается и управляется **всё**, включая настройки, не только табло.
- [ ] Если переключение режима не подтверждено, возвращаемся к прежнему без риска потерять меню.
- [ ] Смена темы не влияет на значения времён, безопасность и состояние расписания.
- [ ] Для двух тем есть настоящие Compose-скриншоты portrait, landscape, CW/CCW; все 8 строк видны.
- [ ] В Release нет тестовых времён, пока не импортирован утверждённый календарь.
