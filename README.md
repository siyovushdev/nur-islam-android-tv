# Нур Ислам — нативное Android TV табло

Программный offline MVP, Kotlin + Jetpack Compose, один модуль `app`. Две темы Elegant / Classic, Release-настройки с пульта, импорт годового JSON без пересборки APK, проверка/предпросмотр/подтверждение/атомарное сохранение/откат. Сетевых разрешений, HTML, WebView, сервера и фоновых служб нет.

**В APK нет официального календаря.** До импорта утверждённого файла показываются часы и сообщение об отсутствии расписания. Программная проверка не заменяет утверждение времён мечетью и приёмку на физическом ТВ.

## Пользование

1. После установки откройте «Нур Ислам» в TV Launcher. Появится мастер HOME / kiosk; его можно пропустить. [Установка и первый запуск без ADB](docs/TV_SETUP.md). После завершения мастер доступен из настроек HOME; на табло первые 15 секунд показывается подсказка входа.
2. **Нажмите OK пять раз за пять секунд**, затем выберите «Открыть настройки администратора». Работает без MENU, клавиатуры и сенсорного экрана; MENU также поддерживается.
3. UP/DOWN — выбор, OK — действие, BACK — назад/к табло. Имена редактируются встроенной клавиатурой с четырьмя направлениями D-pad; «Готово» сохраняет, BACK отменяет.
4. Выберите Elegant / Classic, язык (татарский, русский, оба), масштаб 85/100/115%, подписи и режим экрана. Темы переключаются без рестарта и не меняют расписание.
5. Изменение ориентации сначала показывается как предпросмотр. Выберите подтверждение за 15 секунд; иначе, при BACK, уходе в фон или пересоздании Activity восстановится сохранённый режим.
6. В разделе «Расписание» импортируйте полный годовой JSON, проверьте источник, год, ревизию, статус и сравнение времён. Подтвердите утверждение источника мечетью, затем применение. `approved=false` применять нельзя.

Вход защищает от случайных нажатий; это **не аутентификация**. Настройки предназначены администратору с физическим доступом к пульту. Универсального PIN нет.

## Телевизоры

- `AUTO`: только по размерам окна, без угадывания физического монтажа.
- `PORTRAIT_NATIVE`: ОС предоставляет портретное окно.
- `PORTRAIT_ROTATE_CW` / `PORTRAIT_ROTATE_CCW`: логический макет 1080×1920 в окне 1920×1080, поворот всего UI на +90° / −90°, включая настройки и экранную клавиатуру.
- `LANDSCAPE`: часы и следующий намаз слева, восемь строк справа.

Размеры адаптируются под окно; 1080×1920 — пропорция дизайна, а не фиксированный layout. UP/DOWN в меню соответствуют пульту, который держат вертикально. Направление программного поворота выбирается на установленном ТВ.

## Расписание

[Формат и правила](docs/SCHEDULE_FORMAT.md). Ключ — полная дата, часовой пояс строго Europe/Moscow. Проверяются все 365/366 дней, уникальность, восемь времён HH:mm, схема, год и метаданные. Неполный `data/schedule_example_2026.json` — пример, **не импортируемый рабочий календарь**.

Смысл `fajrInMosque` по умолчанию `UNCONFIRMED`: утром показывается неопределённость Фаджра, а не ошибочно следующий Зухр. Только после подтверждения источника можно указать `fajrMeaning: "PRAYER_START"`. Это не включает икамат. Иша не выбирается из конфликтующих HTML/Excel автоматически.

Локально сохраняются два поколения календаря в одном атомарном файле с SHA-256. При импорте следующего года текущий предыдущий год продолжает работать по своим полным датам; после полуночи выбирается новый. При отсутствии нужного года часы остаются, чужие даты не подставляются. Откат доступен из настроек с отдельным подтверждением. Подробности хранения, резервного импорта и восстановления — в [инструкции эксплуатации](docs/TV_OPERATIONS.md).

## Сборка и проверки

Нужны **JDK 17**, Android SDK Platform 35, Build Tools 35 и принятые лицензии SDK. Укажите SDK через `ANDROID_HOME`, Android Studio или `local.properties` (не коммитить). Если текущий `JAVA_HOME` — JDK 11, сначала выберите JDK 17.

```bash
./gradlew :app:assembleDebug :app:assembleRelease :app:test \
  :app:lintDebug :app:lintRelease :app:assembleDebugAndroidTest
```

- Debug: `app/build/outputs/apk/debug/app-debug.apk`.
- Release: `app/build/outputs/apk/release/app-release-unsigned.apk`, требует подписи владельца для установки.
- Отчёты: `app/build/reports/`; Compose PNG: `app/build/screenshots/`.
- CI выполняет те же проверки и сохраняет APK, отчёты и рендеры как artifacts. Production-релиз не публикуется.

UI-проверки работают через Robolectric / native Skia, в том числе с **Release MainActivity**. Базовые проверки Compose дополнительно собираются в instrumentation APK; успешная сборка не означает, что он запускался на ТВ.

## Устройство кода

- `data/`: строгий JSON, наблюдаемый `ScheduleRepository`, атомарное хранилище двух поколений.
- `domain/`: единый движок следующего намаза, неопределённости Фаджра, дат/времени, геометрии и входа с пульта.
- `settings/`: сохранение настроек и модель безопасного предпросмотра ориентации.
- `ui/`: одна нативная информационная структура, темы через `BoardThemeId` / `BoardAppearance`, Canvas-декор Elegant, настройки и клавиатура.
- `BoardViewModel`: сериализация операций, чтение SAF/локального файла, отмена чтения, публикация состояния без перезапуска.

Часовой пояс отображения фиксирован для Казани. Минутный snapshot меняет крупные часы и расчёт событий; секундное состояние читает countdown. Возобновление экрана и системные TIME_CHANGED/DATE_CHANGED/TIMEZONE_CHANGED перечитывают Instant.
