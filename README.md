# Нур Ислам — Android TV табло времени намаза

Нативное Android TV приложение для настенных экранов мечети «Нур Ислам» (Казань). Показывает текущее время, дату, расписание намазов и следующий намаз. Должно работать без постоянного интернета и самостоятельно открываться после включения устройства там, где это поддерживает прошивка.

**Статус:** подготовка проекта и согласование требований. **APK ещё не разработан.**

## Принципы

- Только **Kotlin + Jetpack Compose / Android SDK**. Никакого HTML, JavaScript UI или WebView в приложении.
- Дизайн: Google Stitch → утверждённые макеты → нативная реализация в Compose.
- Приоритеты: точность расписания → надёжность экрана → читаемость с расстояния.
- На старте один app-модуль, без собственного сервера и сложной инфраструктуры.
- Расписание offline-first, с привязкой к конкретному году и подтверждённому источнику.
- Автозапуск: оценить HOME/kiosk для **конкретного** ТВ/приставки; один BOOT_COMPLETED не гарантирует открытие Activity.

## Что нужно согласовать до использования в мечети

1. Реальная модель Android TV или приставки; версия Android и ориентация ТВ (16:9 или 9:16).
2. Источник времени Иша: в исходных HTML и Excel на 142 датах разница 5 минут.
3. Значение колонки «Мәчеттә укыла» и отдельно утверждённое время икамата для каждого намаза.
4. Кто утверждает очередной годовой календарь, хиджру и даты Рамадана.

**Важно:** исходные HTML и Excel служат референсами и данными для проверки, а не кодом, который будет встроен в APK.
