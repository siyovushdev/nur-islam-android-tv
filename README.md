# Нур Ислам

Нативное офлайн-табло для мечетей: Kotlin + Jetpack Compose, Android 8.0 и новее.
Один продукт для Android TV и телефона, две темы Elegant / Classic. Без сервера,
геолокации, сетевых разрешений, WebView и расчёта времён вместо загруженного расписания.

## Начать пользоваться

Откройте **Настройки** одним коротким OK на TV или касанием табло на телефоне.
Выберите **Загрузить расписание**, затем файл JSON/XLSX и **Применить**.
Дополнительный JSON в **Загрузить календарь мечети** задаёт икамат, Джума, Рамадан
и события. Галочек утверждения источника нет. Достоверные данные готовит мечеть;
приложение проверяет формат и совместимость, не удостоверяет религиозные решения.

[Короткая инструкция установки и импорта](docs/SIMPLE_INSTALL.md).
[Формат расписания](docs/SCHEDULE_FORMAT.md).
[Формат календаря мечети и примеры](docs/MOSQUE_CALENDAR_FORMAT.md).

В APK нет официального календаря. Полные демонстрационные файлы находятся в
[data/examples](data/examples); сведения об источнике доступны в настройках. Телефон и TV
обрабатывают одинаковые файлы одинаково, включая времена икаматов и ошибки.

## Экран и данные

- Внешний вид: Elegant / Classic, русский / татарский / оба языка, масштаб 85/100/115%.
- AUTO, portrait, landscape, программный поворот CW/CCW для физически вертикального TV.
  Изменение ориентации подтверждается за 15 секунд или автоматически откатывается.
- Мечеть, город и именованный часовой пояс берутся из файлов. Время намаза остаётся
  местным значением из файла. Поддержаны разные регионы без отдельных APK.
- JSON расписания содержит полный год и восемь времён в день. Прямой Excel-импорт
  поддерживает конкретный проверенный шаблон Казани, а не произвольные таблицы.
- Календарь мечети заменяется целиком, без слияния. Расписание и календарь независимы,
  каждый имеет предыдущую версию для отката. Ошибка не заменяет рабочие данные.
- Старые JSON и сохранённые настройки читаются. Неоднозначная колонка Фаджра
  не становится началом молитвы автоматически; относительный икамат требует явной базы.
- Ручные редакторы прежней версии доступны в разделе для специалиста до перехода
  на новый календарь. Обычный пользователь выбирает готовые файлы.

Настройка запуска при включении TV необязательна и не мешает обычному табло.
Телефон не предлагает HOME/Device Owner/kiosk. Поддержка автозапуска зависит от
прошивки; [аппаратная приёмка](docs/HARDWARE_ACCEPTANCE.md) выполняется отдельно.

## Сборка и проверки

JDK 17, Android SDK Platform/Build Tools 35:

```bash
./gradlew :app:assembleDebug :app:assembleRelease :app:assemblePhoneDebug :app:assemblePhoneRelease \
  :app:test :app:lintDebug :app:lintRelease :app:lintPhoneDebug :app:lintPhoneRelease \
  :app:assembleDebugAndroidTest
```

Release APK подписываются существующим внешним постоянным ключом; приватные файлы
и пароли не хранятся в Git. TV: `dev.nurislam.tv`, телефон: `dev.nurislam.tv.phone`.
Они обновляют прежние Release-пакеты без удаления данных. Debug-пакеты отдельные.
[Подпись Release](docs/RELEASE_APKS.md). [Ход завершения и проверки](docs/COMPLETION_STATUS.md).

CI включает все четыре варианта, unit/Compose, lint и проверки на настоящих временных
эмуляторах. Для RC проверяются именно подписанные APK поставки и обновление поверх
предыдущего RC. Снимки Compose/Robolectric и снимки настоящих эмуляторов различаются
в отчётах. Прохождение CI не заменяет физическую проверку телевизора и непрерывный прогон.
